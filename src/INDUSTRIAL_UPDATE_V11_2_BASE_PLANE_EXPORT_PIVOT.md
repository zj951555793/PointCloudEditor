# V11.2 基底平面 / 渲染态导出 / 模型旋转中心

## 1. 框选拟合基底并删除平面以下
- 使用现有矩形/套索/圆形/画刷先选择基底区域。
- 菜单：编辑 -> 基底平面裁剪 -> 由当前选择拟合基底平面。
- 点云选择使用选中点；网格选择使用选中三角形的唯一顶点。
- PCA 最小特征向量作为平面法向，并自动把法向指向模型主体一侧。
- 视图显示半透明平面与黄色中心手柄。
- 左键拖动中心手柄上下移动，沿平面法向调节裁剪高度。
- “应用：删除基底平面以下内容”后：点云软删除平面以下点；网格软删除重心位于平面以下的三角形。
- 使用现有 Editor/MeshEditSession，支持 Undo/Redo。

## 2. 导出当前渲染/编辑状态
- 后台导出仍然先深拷贝，绝不修改场景本体。
- 非纹理点云：只导出未删除点。
- 非纹理网格：只导出当前有效三角形，并在导出私有副本上 compact/remap 顶点。
- 纹理 OBJ：仍保持 TextureResult UV 拓扑，同时根据当前网格 TriangleDeleted 状态跳过不可见三角形。
- 不再把原始 backing arrays 原样写出。

## 3. 模型管理器决定旋转中心
- 模型管理器选中模型时保持当前相机 orientation / distance。
- 只更新 orbit target 到选中模型当前有效几何的世界坐标 BBox 中心。
- sceneRadius 同步到当前模型，保证 near/far 与平移尺度合理。
- 基底裁剪完成后重新计算该模型 pivot。
