# 大点云法线性能优化 v3

本版本针对百万级/千万级点云在工业泊松重建前的 PCA 法线估计做了性能修复。

## 修复项

1. 修复 mm/m 坐标单位混用：大型扫描（BBox 对角线 >= 50）按 mm 坐标解释 `radius_mm`，不再固定乘 0.001。
2. 点云间距由体采样 `cbrt(volume/N)` 改为表面采样 `sqrt(bboxSurfaceArea/N)`，避免自动法线半径失真。
3. PCA 邻域由“收集 vector -> 求均值 -> 再遍历一次协方差”改成单遍一阶/二阶矩累计，去掉每个点的临时 vector 分配。
4. OpenMP 改为静态分块，减少百万点场景下 dynamic 调度开销。
5. 每 65536 点更新一次进度，避免长时间 UI 停在 0%。
6. 已有稳定法线的点直接保留，只计算缺失法线。
7. Poisson 面板的线程数直接传给法线阶段。
8. 法向一致化的半径也使用同一套单位转换。

## 推荐

- 已有扫描法线：关闭“缺失时估算法向”也可以；如果只缺少少量法线，开启后只补缺失点。
- 完全没有法线：线程数建议设为物理核心数附近，例如 16 核设 16。
- 邻域半径建议使用自动值；mm 坐标模型现在会正确得到毫米级半径。
