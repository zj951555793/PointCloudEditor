# Poisson 法线 KNN PCA V5

## 改动

- 法线邻域由固定半径搜索改为精确 KNN KD-tree 搜索。
- 默认 K=24，可选 6~64。
- 新增最大邻域距离（mm），0 表示不限制；用于阻止孤立点跨很远寻找邻居。
- KD-tree 只构建一次，所有点共享；查询阶段 OpenMP 静态并行。
- 每个查询使用固定大小栈数组，不为每个点分配邻居 vector。
- 已有有效法线保持不变，只计算缺失法线。
- PCA 仍使用协方差矩阵最小特征值对应特征向量作为未定向法线。
- Poisson 自动补法线和独立“估算法向”操作使用同一实现。

## 推荐参数

一般结构光/扫描点云：K=24。
噪声较大：K=32。
非常精细且点密：K=16~20。
不建议 K>48，容易把小雕花和锐边过度平滑。

最大邻域距离默认 0（不限制）。如果点云存在远离主体的孤立散点，可设置为实际点间距的 4~8 倍。
